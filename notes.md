0.2 Compiler Basics

Compilation — converts C source code into object code.

Linking — combines object code with required libraries to create an executable.


File Types

.c — source file

.o — object file

.exe — executable


GCC Options

-Wall — enables common warnings.

-Wextra — enables additional warnings.

-g — adds debugging information.


gcc -Wall -Wextra -g hello.c -o hello.exe
